## خلاصه پروژه

پروژه **پرتال جامع دانشگاهی کارانت** یک سامانه یکپارچه مدیریت آموزش عالی است که به طور اختصاصی ویژه **دانشگاه علم و هنر** توسعه یافته است. این سامانه فرآیندهای آموزشی، پژوهشی، مالی و اداری دانشگاه را پوشش می‌دهد.

### اهداف بازمعماری

- **جداسازی بک‌اند و فرانت‌اند** از معماری یکپارچه (Monolithic) به معماری API-driven
- **مدرن‌سازی تکنولوژی‌ها** با استفاده از Laravel 13 (Passport) در بک‌اند و React 19 + Vite 6 + Tailwind 4 در فرانت‌اند
- **عدم تغییر در ساختار دیتابیس** — تمام جداول موجود بدون تغییر باقی می‌مانند

### مدیریت خطاهای API (Exception Handler)

در `bootstrap/app.php` یک هندلر خطای سراسری برای API پیاده‌سازی شده است:

| نوع خطا | کد وضعیت | پیام فارسی |
|---------|---------|-----------|
| `QueryException` (خطای SQL) | 500 | خطایی در پردازش درخواست رخ داده است. لطفاً مجدداً تلاش کنید. |
| `NotFoundHttpException` (مسیر یافت نشد) | 404 | مسیر درخواستی یافت نشد. |
| `HttpException` (خطای HTTP عمومی) | متغیر | خطایی در پردازش درخواست رخ داده است. |
| `Throwable` (سایر خطاها) | 500 | خطای داخلی سرور. لطفاً با پشتیبانی تماس بگیرید. |

این هندلر تضمین می‌کند که جزئیات فنی خطاها (مانند کوئری‌های SQL) به کاربر نهایی نمایش داده نشود.

### داشبورد و منوهای پین‌شده (Dashboard Pins)

**مدل UserPinnedMenu:**
- **فایل:** `app/Models/UserPinnedMenu.php`
- **جدول:** `user_pinned_menus`
- **فیلدها:** `id`, `username` (FK → users.username), `menu_id`, timestamps
- **ایندکس:** کامپوزیت روی `(username, menu_id)`

**کنترلر DashboardController:**

| متد | مسیر | توضیح |
|-----|------|-------|
| `pinnedMenus` | `GET /api/dashboard/pinned-menus` | دریافت لیست menu_idهای پین‌شده کاربر جاری |

**معماری پین در فرانت‌اند:**
- دکمه پین/لغو پین در `TabsBar.tsx` (سمت چپ نوار تب‌ها) قرار دارد
- کلیک روی دکمه، یک optimistic update انجام می‌دهد (UI بلافاصله بروز می‌شود) و سپس درخواست API ارسال می‌شود

- منوهای پین‌شده در بخش "میانبرهای پین‌شده" داشبورد (`DashboardModule.tsx`) نمایش داده می‌شوند

### احراز هویت

- پروتکل: **OAuth2** با Laravel Passport
- نوع توکن: **Bearer Token**
- هدر: `Authorization: Bearer {token}`
- گارد: `api` با `driver => passport`

### سیستم منو و ناوبری

سیستم منوی پروژه به صورت **پویا** بر اساس جدول `accesses` در دیتابیس کار می‌کند:

1. **کنترلر `NavigationController`** — منطق مشابه `Navigation::links()` در پروژه قدیمی را پیاده‌سازی می‌کند
2. **ساختار سلسله‌مراتبی** — منوها از نوع parent/child هستند. آیتم‌های `parent = 'top'` به عنوان منوی اصلی و آیتم‌هایی که `parent` برابر ID یک منوی دیگر هستند به عنوان زیرمنو نمایش داده می‌شوند
3. **فیلتر بر اساس نقش جاری (Current Active Role)** — هر آیتم منو دارای فیلد `roles` (رشته pipe-delimited) است. **فقط نقش فعال فعلی کاربر (`users.role`)** برای فیلتر منوها استفاده می‌شود. نقش‌های فرعی کاربر (از جدول `roles`) در فیلتر منو **نادیده گرفته می‌شوند** تا با تغییر نقش کاربری، منوها کاملاً متناسب با نقش جدید تغییر کنند. این رفتار مطابق منطق پروژه قدیمی (`Navigation::links()`) است که فقط از `Auth::user()->role` استفاده می‌کند.
4. **ترتیب نمایش** — فیلد `ordering` ترتیب نمایش منوها را مشخص می‌کند
5. **فعال/غیرفعال** — فیلد `active` مشخص می‌کند که آیا یک آیتم منو فعال است یا خیر

### ساختار منوها در فرانت‌اند

فرانت‌اند منوها را به دو صورت نمایش می‌دهد:

1. **دسته‌های دارای زیرمنو**: یک دکمه در نوار باریک کناری که با کلیک، کشوی زیرمنوها در ستون مجاور باز می‌شود
2. **دسته‌های بدون زیرمنو**: با کلیک روی دکمه دسته، مستقیماً یک تب جدید باز می‌شود (از طریق `targetId` و `iconName` در `MenuCategory`)

### نحوه تخصیص نقش‌ها

نقش‌ها در جدول `roles` با ساختار زیر ذخیره می‌شوند:
```sql
roles(username, role)
```
- `username`: کلید خارجی به جدول users
- `role`: نام نقش (یکی از مقادیر جدول بالا)

دسترسی کاربران به آیتم‌های منو از طریق مطابقت نقش‌های آن‌ها با فیلد `roles` در جدول `accesses` انجام می‌شود. فیلد `roles` یک رشته pipe-delimited است، مثلاً: `admin|arshad|uni|service|teacher|`

- درخواست‌های دانشجویی

## راهنمای اجرا

### پیش‌نیازها

- PHP 8.3+
- Composer
- Node.js 20+
- MySQL
- VS Code (اختیاری)

### اجرای بک‌اند

```bash
cd E:\wamp64\www\portal_backend

# نصب وابستگی‌ها (یکبار)
composer install

# تنظیم محیط
cp .env.example .env
# ویرایش .env: DB_DATABASE=portal, DB_USERNAME=root, DB_PASSWORD=

# اجرای سرور توسعه
php artisan serve --host=localhost --port=8000
```

بک‌اند روی `http://localhost:8000` در دسترس خواهد بود.

### اجرای فرانت‌اند

```bash
cd E:\wamp64\www\portal_frontend

# نصب وابستگی‌ها (یکبار)
npm install

# اجرای سرور توسعه
npm run dev
```

فرانت‌اند روی `http://localhost:3000` در دسترس خواهد بود.

### بیلد فرانت‌اند (تولید)

```bash
npm run build
```

خروجی در مسیر `dist/` قرار می‌گیرد.
